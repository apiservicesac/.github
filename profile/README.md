## Quiénes somos

Empezamos por analizar cómo trabaja cada empresa: documentamos los procesos, identificamos dónde se pierde tiempo y dinero, y entregamos una hoja de ruta. Después la ejecutamos implementando el ERP, desarrollando el software a medida que falta o montando la infraestructura IT que lo sostiene.

## Servicios

| | Servicio | Qué hacemos |
| :-: | :-- | :-- |
| 01 | **[Consultoría empresarial](https://apiservicesac.com/servicios/consultoria-empresarial)** | Diagnóstico de procesos, requerimientos documentados y hoja de ruta de digitalización por fases. |
| 02 | **[Implementación de ERP](https://apiservicesac.com/servicios/implementacion-erp)** | Odoo configurado por área, migración de datos, integraciones y capacitación del equipo. |
| 03 | **[Software a medida](https://apiservicesac.com/servicios/software-a-medida)** | Aplicaciones web, integraciones entre sistemas, automatización y tableros de indicadores. |
| 04 | **[Infraestructura IT](https://apiservicesac.com/servicios/infraestructura-it)** | Servidores, virtualización, almacenamiento en red, respaldos y redes entre sedes. |

## Cómo trabajamos

`01 Levantamiento` → `02 Diagnóstico` → `03 Diseño de la solución` → `04 Implementación` → `05 Adopción y soporte`

## Nuestros productos

### [Dooservice](https://dooservice.sh) · Panel de control para Odoo

Crea entornos de Odoo, despliega desde GitHub, programa respaldos y recibe alertas, en servidores que siguen siendo tuyos. Con Claude Code y OpenCode en la consola.
